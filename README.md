# Fraud Detection Lab

Simulateur de détection de fraude transactionnelle bancaire — génération
de données simulées, moteur de détection par règles métier, scoring et
dashboard de visualisation.

## Progression
- [x] Génération de données de transactions simulées (avec fraude injectée)
- [x] Moteur de détection par règles métier (4 règles)
- [x] Scoring et priorisation des alertes (Faible/Moyen/Élevé)
- [x] Dashboard de visualisation

## Structure du projet
- `src/` — scripts Python
- `data/` — jeux de données générés
- `docs/` — documentation détaillée de chaque étape
- `notebooks/` — exploration et analyse
